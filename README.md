# Krakozyabra

> *кракозя́бра* (сущ., ж. р.) — нечитаемый бессмысленный текст, возникающий при наборе в неправильной раскладке клавиатуры. Например: «ghbdtn» вместо «привет».

Menu bar приложение для macOS, которое лечит кракозябры. Конвертирует слово, набранное в неправильной раскладке (RU↔EN), по горячей клавише `⇧⌘S` или автоматически на пробеле через биграммную автодетекцию.

Альтернатива Punto Switcher / Caramba Switcher.

## Скачать

[**Последняя версия — Releases**](https://github.com/yuraparkuz/Krakozyabra-app/releases/latest)

Требования: macOS 13+ (Apple Silicon или Intel).

## Установка

1. Скачайте `Krakozyabra-X.Y.Z.dmg` напрямую через браузер (не через Telegram/Slack — они ставят строгий quarantine-flag).
2. Откройте DMG.
3. Перетащите `Krakozyabra.app` в `/Applications`.
4. Запустите. Согласитесь на Accessibility permission (нужно для глобального event tap).

App подписан Developer ID Application + notarized — Gatekeeper откроет без warning'ов.

## Возможности

- **⇧⌘S** — конвертация выделения или последнего слова (RU↔EN)
- **Автодетекция** — биграммный детектор автоматически правит кракозябры на пробеле/пунктуации. Backspace откатывает.
- **Per-app раскладка** — настраивается какая раскладка должна включаться при активации конкретного app
- **Personal dictionary** — список исключений
- **Excluded apps** — терминалы/менеджеры паролей, где app молчит
- **Sparkle auto-update** — следующие версии приходят сами
