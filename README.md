# Кракозябра

> *кракозя́бра* (сущ., ж. р.) — нечитаемый бессмысленный текст, возникающий при наборе в неправильной раскладке клавиатуры. Например: «ghbdtn» вместо «привет».

**Пиши. Я поправлю.** Кракозябра живёт в строке меню macOS и сама исправляет текст, набранный не в той раскладке (русская ↔ английская) — после пробела или прямо во время набора.

## Скачать

[**Последняя версия**](https://github.com/yuraparkuz/Krakozyabra-app/releases/latest) — файл `Krakozyabra-X.Y.Z.dmg` (не «Source code»).

Требования: macOS 13+, Apple Silicon или Intel.

## Установка

1. Откройте DMG и перетащите Кракозябру в «Программы».
2. Запустите её из «Программ».
3. Окно приветствия попросит разрешение «Универсальный доступ» — без него Кракозябра не видит набор. Текст никуда не отправляется.
4. Попробуйте прямо в окне: наберите `ghbdtn` и пробел.

Приложение подписано Developer ID и нотаризовано Apple — macOS откроет его без предупреждений.

## Возможности

- **Автоисправление** — после пробела и прямо во время набора.
- **Двойной Shift** — исправить выделенный текст или последнее слово вручную. Можно добавить своё сочетание клавиш.
- **Переключение раскладки** — после исправлений система сама переходит на нужный язык.
- **Мои слова** — Кракозябра запоминает слова, которые вы отстояли, и больше их не трогает.
- **Раскладки приложений** — какая раскладка включается в каждом приложении.
- **Исключения** — приложения, где Кракозябра молчит (терминалы, менеджеры паролей).
- **Обновления** приходят сами.
